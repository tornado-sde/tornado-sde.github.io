# tornado-sde.github.io

Project page for **TORNADO: Adaptive Latent Stochastic Transport for Calibrated Probabilistic PDE Forecasting** (NeurIPS 2026).

`index.html` is fully self-contained (images and fonts are embedded), so it renders the same opened from disk or served by GitHub Pages.
`assets/og.png` is only the link-preview image used by Slack, X, etc.

## Filling in links
Open `index.html` in a text editor and search for `data-link`. Paste URLs into the empty `href=""` attributes (arXiv, NeurIPS, Poster, Know more).
Buttons with an empty href render as striped "soon" blocks, so the page is safe to deploy before every link exists.
